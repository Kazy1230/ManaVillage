# 05 デザイン

基準は v3 モック(`docs/archive/mock/`)。実装は `web/src/app/globals.css`。

## 方針(Kaz の意見から)

- モダンで、余白を広く。ごちゃごちゃさせない
- 色は明るく。暗い配色は避ける(ダークモードは作っていない)
- ナビゲーションは最小限(記事・掲示板・ログイン/アバター)
- 動きは多めでよい。ただし境界(どこからどこまでが1つの塊か)を明確に
- 記事がメイン。掲示板は導線を置く程度
- 親しみやすさ: 白い背景に、3歳児が描いたような「変な絵」

## 色(CSS 変数)

| 変数 | 値 | 用途 |
|---|---|---|
| `--bg` | `#F3F5FA` | ページの地(淡いグレー) |
| `--surface` | `#FFFFFF` | パネル・カード |
| `--ink` | `#222735` | 文字 |
| `--muted` / `--faint` | `#667085` / `#98A1B3` | 補足の文字 |
| `--line` / `--line-strong` | `#E2E6EE` / `#CDD4E1` | 枠線 |
| `--accent` | `#2F6BFF` | リンク・ボタン(明るい青) |
| `--accent-soft` | `#EAF0FF` | 選択中の背景など |
| `--hl` | `#FFE27A` | 蛍光ペン |
| `--p1`〜`--p6` | パステル6色 | 記事カードのサムネ、カテゴリの色 |

## 文字

- 見出し: Zen Kaku Gothic New(700/900)
- 本文: Noto Sans JP
- 英語の例文・飾り: Newsreader(イタリック)
- `next/font/google` で読み込み

## 部品と動き

- 白いパネル(`.panel`)に 1px の枠線と薄い影で区切る
- 記事カード: ホバーで浮く、サムネの絵が少し拡大、光が横切る
- トップのヒーロー: 最新記事。`phrases` があればフレーズが切り替わり、蛍光ペンが引かれる
- 英語フレーズのティッカー(横に流れる帯)
- スクロールで要素が下から現れる(`animation-timeline: view()` 対応ブラウザのみ)
- 記事ページ: 読了プログレスバー
- `prefers-reduced-motion` のときは全アニメーションを止める

## フッター(`web/src/components/SiteFooter.tsx`)

- 濃紺(`--ink`)の地に白い文字。ページの下端を引き締める
- 左: ロゴ、英語のタグライン(`For Everyone's Learning, For Everyone's Help`。黄色)、サイトの説明、Instagram と YouTube のボタン
- 中央: 「記事」(すべての記事と、記事数の多いタグ上位5つ)。右: 「参加する」(掲示板、スレッドを作る、ログイン/新規登録、ログイン中はマイページ)
- 下段: 著作権表示と運営者名。右下の「↑」ボタンと重ならないよう右に余白を取っている
- SNS のアカウントとタグラインは `web/src/lib/site.ts` にある(変更はここだけ)
- 狭い画面では、ロゴ部分が1段目、リンクの2列が2段目になる

## 「変な絵」(記事イラスト)

- 白い背景、揺れる線、2〜4色、棒人間と丸い顔、吹き出しに英語。上手に描かない
- `web/scripts/doodle.mjs` の関数で描く(`person`, `bubble`, `line`, `poly`, `ellipse`, `text`, `star`, `heart`, `arrow` など)。SVG フィルタでクレヨンのかすれを出す
- ワークフロー導入後の記事: `web/content/illustrations/<slug>/core.mjs` に描画コード → `node scripts/illustrate.mjs <slug>` → `public/illustrations/<slug>/core.webp`
- イラストは飾りではなく説明そのもの。1枚で記事の核の概念が伝わるようにする(ワークフロー 3-4)
- 実在の人物・キャラクター・ロゴは描かない
