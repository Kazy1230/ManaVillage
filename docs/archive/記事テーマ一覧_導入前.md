## 調査メモ（参照した記事）

構成・例文・絵はすべて独自に作成。以下は「よく扱われる論点」を確認するために読んだもの。

- how-are-you：Best Teacher Blog / All About / シェーン英会話 / ネイティブキャンプ など。共通論点は「How are you? はあいさつ」「Good, Not bad, Can't complain」。What's up? との違いを扱う記事は少なかった
- me-too-me-neither：Weblio英会話コラム / VoiceTube / NOVA / Yahoo!ニュース エキスパート など。hate（肯定文）と never（否定）の見分けは手薄だった
- see-look-watch：ECC / レアジョブ / 進研ゼミ / Gaba など。映画の see と watch の使い分けは記事によって説明がまちまち
- by-until：Gaba / Kimini / Bizmates など。「ずっと」を入れる判定法は複数の記事で共通。not ... until まで扱う記事は少ない
- polite-no：ネイティブキャンプ / ECC / レアジョブ / Weblio など。「No thank you は失礼」と断定する記事もあるが、言葉自体はていねいなので本記事では断定しない
- would-like：Weblio 忍者英会話 / english-fan など。I'd like to + 名詞 の誤りを扱う記事は少ない
- maybe-probably：ネイティブキャンプ / ECC / レアジョブ など。確率の数字は記事ごとに幅があるため「目安」と明記
- a-and-the：ECC / ネイティブキャンプ / 四谷学院 など。数えられない名詞・複数形は別記事に回す
- l-and-r：Bizmates / レアジョブ / Weblio / ENGLISH JOURNAL など。舌の位置の説明を辞書・発音教材の一般的な記述で確認
- english-diary：ECC / PROGRIT / ベルリッツ など。「3行・短時間・完璧を求めない」はどの記事も共通

- 勉強法シリーズの研究：Dunlosky ら（2013, Psychological Science in the Public Interest）、Karpicke & Roediger（2008, Science）、Godden & Baddeley（1975）と Murre（2021）の追試、Kroll & Stewart（1994）、Dewaele & MacIntyre（2014）。インタラクション仮説（Long）、Willingness to Communicate は概念紹介のみ
