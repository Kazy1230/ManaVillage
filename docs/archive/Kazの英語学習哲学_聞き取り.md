# Kaz の英語学習哲学 v1.0

2026-09-29〜30 の聞き取りをもとにまとめたもの。まなビレッジで「英語の勉強方法」の記事を書くときの軸にする。

---

## 1. いちばん大事にしていること

**勉強そのものを楽しんでもらうこと。**

楽しければ続けられる。続けられれば、できないことはなくなる。できることが増えれば自己肯定感が上がって、人生全体が楽しくなる。

「研究（学習法）」にこだわるのも同じ理由。正しい方法を知っていれば、勉強はもっと楽しくなる。

## 2. 学習の原則

### ① 土台は「単語帳1冊＋文法書1冊」
- いちばん伸びたと感じたのは、英文法書を1冊やり切ったときと、単語帳を1冊ほぼ覚えたとき
- 単語を知っていれば、そのあとの文法・リスニング・スピーキングで「あれ、この単語なんだっけ」とつまずく場面が減る。いちばん最初にやってほしいこと
- 単語帳は、文法書でカバーしきれない例外的な表現も一緒に補ってくれる

### ② 覚えるのは単語より「例文」を、発音付きで
- 寝る前に布団の中でふと思い出すくらいまで繰り返す

### ③ 効率がすべて
- マーカーを引く、書いて覚える、勉強道具をきれいに保つのは無駄
- 覚えたものは、もう必要ない。**覚えたページは破り捨てる**くらいの覚悟で（自称「過激派」）
- 2周目をしたくなったら、もう1冊買えばいい。お金より学習のほうが大切

### ④ 日本語を経由しない
- 「覚えた」の判定は、**頭の中でイメージできるかどうか**だけ
- 日本語訳を言えることは目指さない。その結果、今でも日本語より先に英語が出てくることがある

### ⑤ 聞き流すだけではダメ。口に出し、景色や気持ちと結びつける
- 「聞き流すだけで身につく」はウソ
- ただし、**知っている英語を聞きながら口ずさむ**のは、移動中の学習として最高
- その次の段階は**独り言**。通勤や通学の途中で、見えたものや感じたことを英語で言う（頭の中で考えるだけでもいい）。実際の景色や感情と結びつくので、話すときに記憶から引き出しやすくなる

### ⑥ 環境より「何をするか」
- 留学すれば話せるようになるかは、何をするか次第。ずっと引きこもっていれば伸びない
- 授業で人に話しかける、先生と交流する。そういう積極性が英語力もコミュ力も伸ばす

## 3. 具体的なやり方

### 単語帳の回し方
1. 最初は1日200語で、1冊を2周
2. そのあとは1日300語。毎日「今日の300語」に、前日分と前々日分の復習を足す

| 日 | その日にやる単語 | 合計 |
|---|---|---|
| 1日目 | 今日の300 | 300 |
| 2日目 | 今日の300＋1日目の復習 | 600 |
| 3日目 | 今日の300＋2日目の復習＋1日目の復習 | 900 |
| 4日目以降 | 今日の300＋前日の復習＋前々日の復習 | 900 |

- 「覚えた」の判定は、頭の中でイメージできるかどうか

### 文法書の進め方
- 1冊を1か月以内に完璧にする（1週間で1周読むことは可能）
- 知っているところは読み飛ばすか、破る
- 使っていたのは Vision Quest

### 始める順番
- 基礎がある人：単語帳と文法書を**同時進行**
- 基礎がない人：初心者向けの文法書を1冊終える → 単語帳＋一般レベルの文法書

### 英語がまだ出てこない初心者の独り言
- 言いたいことが英語で出てこなければ、その場で調べる
- 調べた表現をメモして、繰り返し使う。そのうち自然に言えるようになる
- （そのうち物を落としたときに悪い言葉まで出てくるようになるので要注意、というオチ付き）

### つらい時期の乗り越え方
- 楽しい英語学習 YouTube を見る（ケヴィン英会話、ニック式英会話など）
- YouTube の英語を目をつぶって聞きながら、ひたすら耐えた時期もあった。ただし、これは他の人にはつらい方法なので、読者にはすすめない

## 4. 関連しそうな研究（記事にする前に原典を確認すること）

Kaz の考えの多くは、学習研究の知見と方向性が一致している。記事では「研究でもこう言われている」という裏付けとして使える。

| Kaz の考え | 関連しそうな研究・概念 |
|---|---|
| マーカーは無駄 | Dunlosky ら（2013）の学習法比較で、マーカー・下線引きは「効果が低い」と評価 |
| 例文を寝る前に思い出す | 同じ研究で、思い出す練習（想起練習・テスト効果）と間隔をあけた復習は「効果が高い」と評価 |
| 前日・前々日の復習を回す | 分散学習（間隔反復）の考え方 |
| 覚えたページを破る | 覚えたものを外し、未習得のものに時間を集中させる（単語カードアプリの間隔反復と同じ発想） |
| 日本語を経由せずイメージで覚える | 改訂階層モデル（Kroll & Stewart, 1994）。上達につれて「英単語→意味」が直接つながる |
| 独り言が景色と結びつく | 文脈依存記憶（覚えたときの状況と一緒に記憶される）。本人は「場所記憶法」に近いと感じているが、厳密には別の概念なので記事では区別する |
| 積極的に話しかける人が伸びる | インタラクション仮説（Long）、コミュニケーションへの積極性（Willingness to Communicate） |
| 楽しさが継続を生む | 外国語学習の楽しさ（Foreign Language Enjoyment：Dewaele & MacIntyre）の研究 |

**書くときの注意**
- 「頭のよさや記憶力より、コミュ力が大切」は言い切らない。言語適性（記憶力など）も成果に関わるという研究がある。記事では「コミュ力は才能と違って、今日から伸ばせる武器」のように書く
- 数字（〇％効果が上がる など）は、原典で確認できたものだけ使う
