## 2026-09-29: 技術の決定とバックエンド実装

- 「Vercel 無料プランで Next.js と FastAPI はできない？」→ できるが、**Next.js + Supabase(FastAPI なし)を推奨**し決定
  - 要件は CRUD 中心。Supabase の認証と RLS で足りる。アプリが1つで管理が楽
  - 将来の拡張(学習者の画面、学習データの分析)も、Supabase は普通の Postgres なので対応できる。Python が必要になったら後から足す
- 掲示板のカテゴリ(要件の未決定事項)は **学習者が自由に作れる**に決定
- Next.js 16 で実装(`docs/02-architecture.md`)。Supabase のプロジェクトは Kaz が作成し、SQL を実行
- Vercel にデプロイ(最初は `manavillage.vercel.app`)。Resend のキーも設定
