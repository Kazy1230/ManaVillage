「英語の独り言が、スピーキングの練習になるよ」

そう聞いて、試してみようと思ったあなた。朝、駅に向かって歩きながら、さっそく英語で何か言おうとします。

…何も出てこない。

目の前の信号が赤になった。「赤信号」って英語でなんだっけ。そもそも「信号」がわからない。結局、何も言えないまま駅に着いてしまいました。

大丈夫です。**最初はみんなそうです。** 僕も独り言を始めたばかりのころは、ほとんど何も出てきませんでした。

## 出てこないのは、まだ「持っていない」だけ

英語が出てこないのは、才能がないからではありません。その表現を、まだ頭の中に**持っていない**だけです。

持っていないものは、出しようがありません。だから最初のうちは、独り言は「話す練習」というより、**自分が言いたいのに言えない表現を見つける作業**だと思ってください。

## 3ステップ：調べる → メモ → くり返す

![スマホで「赤信号って…?」と調べる棒人間から矢印が伸びて、「MEMO red light / crosswalk / I'm late!」と書かれたメモがある絵](/articles/self-talk-beginners/1.svg)

### ステップ1：言えなかったら、その場で調べる

言いたいのに出てこなかった言葉は、スマホでさっと調べます。僕も最初のころは、いちいち調べながらやっていました。

### ステップ2：メモしておく

調べた表現は、スマホのメモに残しておきます。

<div class="example"><span class="lbl">MEMO</span><span class="en">red light / crosswalk / I'm late! / It's so crowded.</span><span class="ja">赤信号 / 横断歩道 / 遅れる！ / 混んでるなあ</span></div>

### ステップ3：同じ場面で、くり返し使う

次の日も、同じ道を歩きます。赤信号で止まったら、今度は言えるはずです。

<div class="example"><span class="lbl">EXAMPLE</span><span class="en">Oh, a <mark class="hl">red light</mark>. I'm going to be late!</span><span class="ja">あ、赤信号。遅刻しそう！</span></div>

通勤や通学の道は、毎日ほとんど同じです。同じ場面で、同じ表現を何度も使うことになる。この「くり返し」が、いつの間にか表現を自分のものにしてくれます。場面と一緒に覚えると思い出しやすい理由は、[覚えた「場所」と「気持ち」ごと思い出せる？](/articles/context-memory)で紹介しています。

## 最初は「単語だけ」でいい

いきなり文で言おうとしなくて大丈夫です。最初は、目に入ったものを単語で言うだけで十分です。

- *"Cat."*（猫）
- *"Convenience store."*（コンビニ）
- *"Rain."*（雨）

慣れてきたら、ひとこと足します。

- *"A cat. So cute."*（猫だ。かわいい）
- *"Rain again..."*（また雨か…）

## 声に出せないときは、頭の中でOK

電車の中や、人の多い場所で声に出す必要はありません。頭の中で考えるだけでも、立派な独り言の練習です。

## 気をつけてほしいこと（笑）

独り言を続けていると、だんだん英語が勝手に出てくるようになります。すると、物を落としたときなどに、とっさに汚い英語が出てきてしまうことがあります。

実際、僕はありました。人前では気をつけてください。

単語で言えるようになってきたら、[通勤中の独り言が、スピーキングの「引き出し」を作る](/articles/self-talk)で文の独り言にステップアップしましょう。まちがえるのが不安な人は[まちがえるのが怖いあなたへ](/articles/mistakes-ok)もどうぞ。

## まとめ

- 英語が出てこないのは、まだその表現を持っていないだけ
- 言えなかったら調べる → メモする → 同じ場面でくり返す
- 最初は単語だけでいい。慣れたらひとこと足す
- 声に出せないときは、頭の中でOK
