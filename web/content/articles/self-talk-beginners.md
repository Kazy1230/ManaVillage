「英語の独り言が、スピーキングの練習になるよ」

そう聞いて、朝、駅に向かって歩きながら、さっそく英語で何か言おうとする。…何も出てこない。目の前の信号が赤になった。「赤信号」って英語でなんだっけ。結局、何も言えないまま駅に着いてしまった。こんな経験はありませんか。

大丈夫です。**英語の独り言が出てこないのは、最初はみんな同じ**です。この記事では、ひとことも出てこない状態から、「単語だけ → ひとこと → 1文」と3段階で進める方法と、言えなかった表現を自分のものにする手順を紹介します。

## 出てこないのは、まだ「持っていない」だけ

英語が出てこないのは、才能がないからではありません。その表現を、まだ頭の中に**持っていない**だけです。

初めて入った店で、メニューの名前を知らないまま注文しようとすると、口が止まりますよね。あれと同じです。知らない言葉は、どれだけ頑張っても、出しようがありません。

だから最初のうちは、独り言を「話す練習」と考えないほうがうまくいきます。**自分が言いたいのに言えない表現を、見つける作業**だと思ってください。言えなかった瞬間は失敗ではなく、「次に覚える表現が見つかった」という成果です。

## 段階1：まずは単語だけでいい

いきなり文で言おうとしなくて大丈夫です。最初は、目に入ったものを、単語ひとつで言うだけで十分です。

<div class="example"><span class="lbl">EXAMPLE</span><span class="en"><mark class="hl">Door.</mark> Bus. Umbrella. Coffee.</span><span class="ja">ドア。バス。傘。コーヒー。</span></div>

ポイントは3つです。

- 名詞だけでよい。`a` や `the`、複数形の `s` は、気にしない
- 知っている簡単な単語から。難しい単語を探さない
- 言えなかったものだけ、あとで調べる(次の章で説明します)

「簡単すぎて意味がないのでは？」と思うかもしれません。でも、歩きながら目に入ったものに、ぱっと英語が浮かぶようになるには、この段階がいちばん大事です。言える単語が増えるほど、次の段階に進みやすくなります。

## 段階2：ひとこと足す

単語が出てくるようになってきたら、気持ちや状態を**ひとこと**足します。主語も動詞も、まだいりません。

<div class="example"><span class="lbl">EXAMPLE</span><span class="en"><mark class="hl">Rain</mark> again...</span><span class="ja">また雨か…</span></div>

<div class="example"><span class="lbl">EXAMPLE</span><span class="en">Cold coffee. <mark class="hl">Nice.</mark></span><span class="ja">冷たいコーヒー。いいね。</span></div>

<div class="example"><span class="lbl">EXAMPLE</span><span class="en">So crowded. / Too early. / Sleepy...</span><span class="ja">めっちゃ混んでる。/ 早すぎ。/ 眠い…</span></div>

形は「単語 + 気持ちを表す語」です。`So`(とても)や `Too`(〜すぎる)、`again`(また)は、ひとことに足しやすい便利な語です。日本語の独り言も、「うわ、混んでる」「眠…」のように、文になっていないことが多いですよね。英語でも、それで問題ありません。

## 段階3：1文にしてみる

ひとこと言うのに慣れたら、短い**1文**に挑戦します。最初は、次の3つの型だけで足ります。

| 型 | 例 | 意味 |
|---|---|---|
| I'm + 状態 | I'm hungry. / I'm late. | お腹すいた / 遅れてる |
| It's + 天気・状況 | It's raining. / It's cold today. | 雨だ / 今日は寒い |
| I want + もの | I want coffee. | コーヒーがほしい |

<div class="example"><span class="lbl">EXAMPLE</span><span class="en">Oh, a red light. <mark class="hl">I'm late!</mark></span><span class="ja">あ、赤信号。遅れる！</span></div>

進む目安は、「いまの段階の言い方が、詰まらずに出てくるようになったら」です。何日で次へ、と決める必要はありません。ひとこと段階で楽しければ、しばらくそこにいて大丈夫です。

1文で言えるようになったあとの練習は、[通勤中の独り言が、スピーキングの「引き出し」を作る](/articles/self-talk)で紹介しています。この記事は、そこにたどりつく前の、ゼロからの入り口です。

## 言えなかったら「調べる → メモ → くり返す」

どの段階でも、言いたいのに言えなかった表現が出てきます。そのときの手順は、3ステップです。

![スマホで「赤信号って…?」と調べる棒人間から矢印が伸びて、「MEMO red light / crosswalk / I'm late!」と書かれたメモがある絵](/illustrations/self-talk-beginners/core.webp)

### ステップ1：言えなかったら、調べる

言いたいのに出てこなかった言葉は、スマホの辞書や翻訳アプリでさっと調べます。立ち止まれない道なら、あとで調べるために、何が言えなかったかだけ覚えておきましょう。

調べるとき、長い文が出てきたら、短い言い方に直します。たとえば「電車が遅れていて困る」を調べて長い訳が出てきたら、`The train is late.` のような、短い形にして持ち帰ります。独り言で使うのは、短い言い方で十分です。

### ステップ2：メモしておく

調べた表現は、スマホのメモに残します。日本語と英語を並べて、1行ずつ書くだけです。

<div class="example"><span class="lbl">MEMO</span><span class="en">red light / crosswalk / I'm late! / It's so crowded.</span><span class="ja">赤信号 / 横断歩道 / 遅れる！ / 混んでるなあ</span></div>

どんな場面で言いたかったのかも、ひとこと書いておくと、あとで見返したときに思い出しやすくなります。

### ステップ3：同じ場面で、くり返し使う

次の日も、同じ道を歩きます。赤信号で止まったら、今度は言えるはずです。

<div class="example"><span class="lbl">EXAMPLE</span><span class="en">Oh, a <mark class="hl">red light</mark>. I'm going to be late!</span><span class="ja">あ、赤信号。遅刻しそう！</span></div>

通勤や通学の道は、毎日ほとんど同じです。同じ場面で、同じ表現を何度も使えます。場面と英語を結びつける考え方は、[覚えた「場所」と「気持ち」ごと思い出せる？](/articles/context-memory)で紹介しています。

<div class="voice"><span class="lbl">運営者の体験</span><p>運営者自身も、英語が出てこなかった頃は、いちいち調べてメモし、繰り返すうちに言えるようにしました。</p></div>

## こんなときはどうする？

### 調べるのが面倒で、続かない

全部を調べようとしないでください。**1日に1つだけ**、いちばん言いたかったものを調べれば十分です。調べる数が少なくても、同じ場面でくり返せば、それは確実に残ります。

### 人が多くて、声に出せない

電車の中や人の多い場所で、声に出す必要はありません。頭の中で考えるだけでも、立派な独り言の練習です。人通りの少ない道だけ、小さく声に出してみる、という使い分けもできます。

### 合っているか不安で、言えない

独り言は、誰にも聞かれません。文法が少し違っていても、誰も困りません。まちがえるのが怖くて口が止まってしまう人は、[まちがえるのが怖いあなたへ。独り言なら、誰にも聞かれない](/articles/mistakes-ok)もどうぞ。

### 単語を言うだけで、本当に練習になる？

英語を頭に浮かべる練習にはなります。この段階の目的は、「話せる」ことではなく、英語を頭に浮かべる習慣をつくることです。単語の次は、ひとこと、1文と、少しずつ進めば大丈夫です。すでに知っている英語を声に出すところから始めたい人は、[口ずさみ](/articles/mumble-commute)から入る方法もあります。

## 気をつけてほしいこと（笑）

もし、物を落としたときなどに、とっさに英語が**つい口から出てしまう**日が来たら、ちょっと楽しいですよね。ただ、そういうときに出てくるのは、あまり上品でない言葉かもしれません。人前では、気をつけてください。

## 次にやること

今日やることは、ひとつだけです。**いま目の前にあるものを、英語の単語で1つ言ってみてください。** 言えなかったら、それが今日調べる1語です。

単語が言えるようになったら、ひとこと、1文へ。そのあとは、[独り言のやり方](/articles/self-talk)で、場面と気持ちをつなげる練習に進めます。
