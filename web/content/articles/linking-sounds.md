知っている単語ばかりなのに、ネイティブの英語になると聞き取れない。その原因の多くは、単語と単語がつながって音が変わる「リンキング」です。この記事では、英語のリンキングを3つの型に分けて、聞こえ方、なぜ起きるか、聞き取りのコツ、練習のしかたまで整理します。

![check it out が「チェキラウ」、big game が「ビッゲイム」、get over が「ゲロウヴァー」のように、単語のあいだが切れずにひと続きの音になる様子を3段で示した絵](/illustrations/linking-sounds/core.webp)

## そもそも、なぜ音はつながるのか

文字で見る英語は、単語ごとに空白で区切られています。でも、話し言葉に空白はありません。人は息をひと続きに流しながら話すので、単語の終わりの音と、次の単語のはじめの音が、自然にくっついたり、混ざったりします。

日本語でも同じです。「ありがとうございます」を、「あ・り・が・と・う・ご・ざ・い・ま・す」と一音ずつ区切って言う人はいませんよね。「ありがとーございます」とひと続きに言います。英語のリンキングは、それと同じことが、英語のルールで起きているだけです。

なお、ここで挙げるカタカナは、あくまで聞こえ方の目安です。英語の音は、カタカナでは正確に書けません。「そう聞こえるかも」くらいの気持ちで見てください。

## 型1: 子音 + 母音は、くっつく

### 聞こえ方

前の単語が子音で終わり、次の単語が母音で始まると、その子音が次の単語の頭に移ったように聞こえます。

<div class="example"><span class="lbl">EXAMPLE</span><span class="en"><mark class="hl">check it out</mark></span><span class="ja">「チェック・イット・アウト」ではなく、「チェキラウ」に近く聞こえることがあります。</span></div>

<div class="example"><span class="lbl">EXAMPLE</span><span class="en">Turn <mark class="hl">it on</mark>.</span><span class="ja">「ターン・イット・オン」ではなく、「ターニトン」に近く聞こえることがあります。</span></div>

<div class="example"><span class="lbl">EXAMPLE</span><span class="en">Pick <mark class="hl">up</mark> a pen.</span><span class="ja">「ピック・アップ」ではなく、「ピカップ」に近く聞こえることがあります。</span></div>

### なぜ起きるか

母音は、口をあけて息を流す音です。子音で止まってから、もう一度母音をはじめるより、子音を次の母音の頭に使ってしまうほうが、口の動きがなめらかです。そのため、子音と母音が、ひとまとまりの音になります。

### 聞き取りのコツ

コツは、「耳が単語の切れ目を探さない」ことです。文字で見ると3語でも、音では「チェ・キ・ラウ」のようなひと続きになっています。文字で見た単語のまとまりではなく、「子音＋母音」の音のまとまりで聞く、と意識してみてください。

### 練習のしかた

1. 聞き取れなかった英文を、スクリプトで確認します。
2. 子音で終わる単語と、母音で始まる単語が並ぶ場所に、下線を引きます。
3. 下線の部分を、止まらずに1つの単語のように、声に出して読みます。

慣れないうちは、なかなか聞き取れなくて当然です。何もない所で躓くことってありますよね。あれと同じで、音がつながる所は、最初は耳が引っかかります。

## 型2: 同じ子音が続くと、1回になる

### 聞こえ方

前の単語の終わりと、次の単語の始まりが、同じ子音のとき、2回言わず、ひとつながりの音になります。

<div class="example"><span class="lbl">EXAMPLE</span><span class="en">bi<mark class="hl">g g</mark>ame</span><span class="ja">g を2回言わず、少しためてから1回だけ発音します。</span></div>

<div class="example"><span class="lbl">EXAMPLE</span><span class="en">star<mark class="hl">t t</mark>ime</span><span class="ja">t を2回言わず、舌を止めてから1回だけ破裂させます。</span></div>

<div class="example"><span class="lbl">EXAMPLE</span><span class="en">sa<mark class="hl">me m</mark>essage</span><span class="ja">m を2回言わず、長めの m を1回だけ言います。</span></div>

### なぜ起きるか

同じ位置に口を作る音が続くと、わざわざ離してまた作り直すのは面倒です。そのため、口の形を保ったまま、少し長く音を出します。

Baruch College(ニューヨーク市立大学)の発音教材 Tools for Clear Speech は、こう説明しています。p, t, k, b, d, g のような止める音は、いつもより長くためてから放す。s, m, n, l のように続けて出せる音は、単音より少し長く伸ばす。

### 聞き取りのコツ

「ためる時間」が、ヒントになります。big game は、音が消えたように一瞬止まって、そのあとに game が始まります。big aim との違いが、この「間」です。この「間」が、単語の切れ目のサインだと思うと、聞き取りが楽になります。

### 練習のしかた

- star**t t**ime と star time(スタータイム)を、続けて口に出してみる
- 同じ子音がつながる表現(good day、same message、this city など)を、声に出して読む
- 音声を聞いて、2つの音が「1つに聞こえる所」に印をつける

## 型3: t や d は、弱くなったり消えたりする

t や d は、英語のリンキングで、いちばん聞き取りにくい音です。聞こえ方が、いくつかに分かれます。

### 3-1. 間の t が、ラ行のような音になる(フラップ)

アメリカ英語では、t や d が母音と母音にはさまれると、舌先を軽く1回はじく音(たたき音)になります。これを、フラッピング(flapping)と呼びます。日本語のラ行に近く聞こえることがあります。

<div class="example"><span class="lbl">EXAMPLE</span><span class="en">wa<mark class="hl">t</mark>er / bu<mark class="hl">tt</mark>er</span><span class="ja">「ウォーター」「バター」ではなく、「ウォーラー」「バラー」に近く聞こえることがあります(アメリカ英語)。</span></div>

<div class="example"><span class="lbl">EXAMPLE</span><span class="en">ge<mark class="hl">t o</mark>ver</span><span class="ja">単語の間でも、母音にはさまれると起きます。「ゲロウヴァー」に近く聞こえることがあります。</span></div>

Wikipedia の Flapping の項によると、単語の中では、t や d が、強く読まれる母音と、弱く読まれる母音の間に入るときに起きます。単語をまたぐ場合は、あとの単語が母音で始まれば、起きます(get over など)。ただし、例外もあり、規則できれいに予測するのは難しいそうです。「water は必ずこう」と決めつけず、「そう聞こえることが多い」くらいに捉えてください。イギリス英語では、別の発音になる話者も多くいます。

### 3-2. t や d を、はっきり破裂させない

単語の終わりの t や d の直後に、別の子音が来ると、口を閉じたまま、次の音に移ることがあります。Baruch College の教材は、異なる止め音が続くときは、最初の音を放さずにためてから、次の音をすぐ出す、と説明しています。

<div class="example"><span class="lbl">EXAMPLE</span><span class="en">bi<mark class="hl">g d</mark>eal / ge<mark class="hl">t t</mark>hrough / ol<mark class="hl">d m</mark>an</span><span class="ja">最初の g、t、d は、はっきり聞こえず、口を閉じた「間」だけが残ります。</span></div>

### 3-3. t が、ほとんど聞こえなくなる

早い会話では、子音にはさまれた t が、ほとんど聞こえないことがあります。Wikipedia の Elision(音の脱落)の項には、first light の t が落ちて、firs' light のように発音される例があります。

### なぜ起きるか

どれも、「できるだけ少ない動きで、早く言いたい」という、話し言葉の省エネです。t や d は、舌を止めて、破裂させる、手間のかかる音なので、弱くなりやすいのです。

### 聞き取りのコツ

t が「聞こえるはず」と思って待っていると、聞き逃します。**「t がなくても聞き取れる」**ことを、耳に覚えさせるのがコツです。たとえば、母音にはさまれた「ラ・ダ」のような音が聞こえたら、「ここは t かもしれない」と、頭の中で置き換えてみてください。water が「ウォーラー」と聞こえたら、「あ、water だ」と分かればいいのです。

### 練習のしかた

1. water、better、city、get it など、フラップになりやすい単語を、音声つきの辞書で聞く
2. 自分でも、ラ行に近い音で、声に出して言ってみる
3. 聞き取れなかった文の、t や d の前後に印をつけ、「なくても聞こえる」か確かめる

## おまけ: gonna のような縮約との関係

going to が「ガナ」に聞こえるのは、リンキングとは少し別の仕組みです。Wiktionary によると、gonna は going to の口語的な縮約形で、書くとかなりくだけた印象になります。単語の間で音がつながるのではなく、よく使う表現が、ひとつの短い語に固まったものです。

<div class="example"><span class="lbl">EXAMPLE</span><span class="en">I'm <mark class="hl">gonna</mark> call you.</span><span class="ja">I'm going to call you. と同じ意味。話し言葉では、こう聞こえることがよくあります。</span></div>

ただし、Wiktionary が指摘するとおり、gonna が使えるのは「これから〜する」という未来の意味のときだけです。I'm going to the mall.(ショッピングモールへ行くところ)のような、場所へ向かう意味の going to は、gonna にはなりません。

## 聞き取れるようになる、全体の練習手順

型を知っても、それだけで聞き取れるようにはなりません。理解したうえで、耳と口で何度か確かめる必要があります。

1. **短い音声を選ぶ。** 10〜30秒ほどの、スクリプトがあるものにします。日本語字幕でなく、英語のスクリプトを使います。
2. **まず聞いて、書き取る。** 聞こえたとおりに、分かる所だけ書きます。
3. **スクリプトで答え合わせ。** 聞き取れなかった所に、3つの型のどれかを当てはめます。
4. **その部分だけ、何度も聞く。** 「なるほど、つながっているのか」と分かったうえで聞くと、音が違って聞こえます。
5. **真似して、声に出す。** つながり方まで、そっくり真似します。

この方法は、[聞き流しではなく口ずさむ練習](/articles/mumble-commute)と相性がよいです。聞き取れた音を、自分の口で出せるようにすると、音が身近になります。また、リンキングは、単語よりも、[例文のかたまりで覚える](/articles/example-sentences)と、自然に身につきます。check it out のように、ひとまとまりで、音ごと覚えてしまうのです。

## よくある疑問

### リンキングを、自分でもやらないといけませんか？

まずは聞き取れることが先です。話すときは、単語を1語ずつ、はっきり言っても、通じます。ただ、つながる話し方を真似していると、自然に言えるようになることが多いです。

### 音をつなげたら、カタカナ英語になりませんか？

カタカナで覚えた「チェキラウ」を、そのまま言うのは、おすすめしません。カタカナは、聞こえ方の目安です。英語の音で、つなげて読む練習をしてください。

### 全部、聞き取らないとだめですか？

いいえ。ネイティブ同士でも、聞き返すことはあります。聞き取れなかった所は、次の場面で、また聞けばいいのです。まずは、よく出てくる型から、ひとつずつ。

## まとめ: 次にやること

今日、英語の音声を聞く機会があれば、聞き取れなかった一文を、書き出してみてください。その一文が、3つの型のどれに当てはまるかを探すだけでも、耳の使い方が変わります。[独り言で、自分の口を動かす](/articles/self-talk)ときも、その一文を、つなげて言ってみてください。
