「ペンを借りてもいいですか」「ここに座ってもいいですか」。この「してもいいですか」を英語で言うとき、まず浮かぶのは *Can I …?* だと思います。間違いではありませんが、相手や場面によっては、くだけすぎることがあります。この記事では、許可を求める5つの言い方を丁寧さの段階で並べ、場面ごとの使い分け、そして返事のしかたまで見ていきます。

![許可を求める言い方の、丁寧さの階段](/illustrations/asking-permission/core.webp)

## 許可の求め方は「丁寧さの階段」で考える

Cambridge Dictionary の文法ページには、許可を求める can、could、may の丁寧さが、次の順で示されています(出典は記事の末尾)。

- *Can I ask you a question?*(くだけた言い方)
- *Could I use your phone?*(より丁寧)
- *May I use your phone?*(さらに丁寧)

ここに、*Do you mind if I …?* や *Would it be OK if I …?* のような、文の形が違う言い方が加わります。この記事では、5つを次の目安で並べます。あくまで目安で、同じ言い方でも声の調子や相手との関係で、印象は変わります。

| 言い方 | 丁寧さの目安 | 向いている相手・場面 |
|---|---|---|
| Can I | カジュアル | 友だち、家族、気心の知れた同僚 |
| Is it alright if I | ふつう | 知り合い、近所の人、同僚 |
| May I | 丁寧 | お客さん、初対面、目上の人 |
| Do you mind if I | 丁寧 | 相手の都合に関わることを頼むとき |
| Would it be OK if I | とても丁寧 | 上司への相談、断られるかもしれないお願い |

## 友だち・同僚なら Can I

いちばん手軽で、よく使われる形です。気を使わなくてよい相手なら、これで十分です。

<div class="example"><span class="lbl">EXAMPLE</span><span class="en"><mark class="hl">Can I</mark> borrow your pen for a sec?</span><span class="ja">ちょっとペン借りていい？</span></div>

<div class="example"><span class="lbl">EXAMPLE</span><span class="en"><mark class="hl">Can I</mark> sit here?</span><span class="ja">ここ座っていい？</span></div>

*for a sec* は「ちょっとのあいだ」という、くだけた言い方です。返事は *Sure.*、*Of course.*、*Go ahead.* などで、軽く返せます。

*Can I* が初対面や目上の人に絶対にだめ、というわけではありません。ただ、ていねいに話したい場面では、もう一段上の形を選んだほうが安心です。

## ふつうの丁寧さなら Is it alright if I

「〜しても大丈夫ですか」というニュアンスで、かしこまりすぎず、くだけすぎない中間の言い方です。*alright* は *all right* とも書きます。

<div class="example"><span class="lbl">EXAMPLE</span><span class="en"><mark class="hl">Is it alright if I</mark> sit here?</span><span class="ja">ここに座ってもいいですか？</span></div>

<div class="example"><span class="lbl">EXAMPLE</span><span class="en"><mark class="hl">Is it alright if I</mark> bring a friend to the party?</span><span class="ja">パーティーに友だちを連れてきてもいいですか？</span></div>

if の後ろは、ふつう現在形です(*sit*、*bring*)。ここを *sat* のような過去形にすると、あとで出てくる *Would it be OK if I* のような、より控えめな形になります。

## お客さん・初対面・目上には May I

Cambridge の文法ページは、may について、許可を求めたり、与えたり、断ったりするのに使い、かなり丁寧な(formal な)言い方だと説明しています。日常会話で多用するとかしこまった印象になりますが、接客や初対面では、ちょうどよい形です。

<div class="example"><span class="lbl">EXAMPLE</span><span class="en"><mark class="hl">May I</mark> ask you a few questions?</span><span class="ja">いくつか質問させていただいてもよろしいですか？</span></div>

<div class="example"><span class="lbl">EXAMPLE</span><span class="en"><mark class="hl">May I</mark> take your coat?</span><span class="ja">コートをお預かりしましょうか？</span></div>

2つ目のように、「相手のために何かをしてよいか」と申し出るときにも、*May I …?* はよく使われます。返事は *Yes, of course.* や *Please do.*、*Certainly.* などです。

一方、友だちどうしで *May I go to the bathroom?* と言うと、ちょっと改まりすぎて、冗談のように聞こえることがあります。ここも、場面に合わせて選べば大丈夫です。

## 相手の都合を気づかう Do you mind if I

直訳は「私が〜したら、気にしますか？」です。相手が嫌でなければ、という気づかいが入るので、窓を開ける、隣の席に座る、電話に出るなど、相手に影響が出る行動の許可に、よく合います。

<div class="example"><span class="lbl">EXAMPLE</span><span class="en"><mark class="hl">Do you mind if I</mark> open the window?</span><span class="ja">窓を開けても構いませんか？</span></div>

<div class="example"><span class="lbl">EXAMPLE</span><span class="en"><mark class="hl">Do you mind if I</mark> take this call?</span><span class="ja">この電話に出てもいいですか？</span></div>

Longman の辞書でも、*would/do you mind* は「許可を丁寧に求めるときに使う」表現として載っています。過去形を使った *Would you mind if I opened the window?* も同じ用途の例として挙がっています。

### 返事のしかた。Yes と No が逆に聞こえる

この表現のいちばんの落とし穴が、返事です。*Do you mind …?* は「気にしますか？」という質問なので、

- 気にしない(=してもいい)なら **No**
- 気にする(=困る)なら **Yes**

になります。日本語の「はい、どうぞ」の感覚で *Yes* と答えると、「はい、気にします」と受け取られかねません。

<div class="example ng"><span class="lbl">NG</span><span class="en">Do you mind if I open the window? — Yes, go ahead.</span><span class="ja">Yes は「気にします」と聞こえてしまう。「どうぞ」のつもりでも、混乱のもとです。</span></div>

<div class="example"><span class="lbl">EXAMPLE</span><span class="en">Do you mind if I open the window? — <mark class="hl">No, not at all.</mark> Go ahead.</span><span class="ja">窓を開けても構いませんか？ — ええ、全然かまいませんよ。どうぞ。</span></div>

Yes か No のどちらで答えるか迷うなら、*Sure, go ahead.* や *Go ahead.* のように、Yes と No を使わない返事にする手もあります。実際の会話では、こうした返事もよく聞かれます。

断りたいときは、*Yes* だけだときつく聞こえやすいので、理由を添えると角が立ちません。

<div class="example"><span class="lbl">EXAMPLE</span><span class="en">Do you mind if I open the window? — Actually, I'm a little cold. Could we keep it closed?</span><span class="ja">窓を開けても構いませんか？ — 実は少し寒くて。閉めたままにしてもらえますか？</span></div>

### もう1つの落とし穴。Do you mind if I と Do you mind -ing

*Do you mind* のあとに *-ing* が続くと、意味が変わります。

- *Do you mind **if I** open the window?* は「私が開けてもいいですか」(許可を求める)
- *Do you mind **opening** the window?* は「あなたが開けてくれませんか」(お願いをする)

誰が動くのかで、許可を求めているのか、お願いしているのかが変わります。Longman にも、*Would you mind waiting outside?* のように、相手に何かをしてもらう例が載っています。

## いちばん丁寧な Would it be OK if I

if の後ろが過去形になっているのが特徴です。「もし〜したとしたら」と、一歩引いた言い方になるので、ぶしつけに聞こえにくくなります。上司への相談や、断られるかもしれないお願いに向いています。

<div class="example"><span class="lbl">EXAMPLE</span><span class="en"><mark class="hl">Would it be OK if I</mark> left a bit early today?</span><span class="ja">今日は少し早めに帰ってもいいですか？</span></div>

<div class="example"><span class="lbl">EXAMPLE</span><span class="en"><mark class="hl">Would it be OK if I</mark> sent you the file tomorrow morning instead?</span><span class="ja">ファイルは、代わりに明日の朝お送りしてもよろしいでしょうか？</span></div>

過去形(*left*、*sent*)ですが、意味は「過去に〜した」ではなく、これからのことです。ここでの過去形は、時間ではなく、控えめさを表しています。

返事は、Yes と No で迷うことはありません。*Sure, that's fine.* や *No problem.* と答えられます。

## 場面で選ぶ。こんなとき、どれを使う？

| 場面 | 選びやすい言い方 |
|---|---|
| 友だちのペンを借りる | Can I borrow your pen? |
| 同僚のデスクの椅子を借りる | Is it alright if I use this chair? |
| 店で商品を試着する | Can I try this on? / May I try this on? |
| 上司に早退を相談する | Would it be OK if I left early today? |
| 電車で隣の人の席に荷物を置く | Do you mind if I put my bag here? |
| 会議で質問する | May I ask a question? |

職場でメールに書くときは、少し丁寧な *Would it be OK if I …?* や *May I …?* を選ぶと安心です。

## 間違いやすいポイント

1. **Yes と No が逆になる**: *Do you mind if I …?* には、OK なら No。前の章のとおりです
2. **if の後ろの形**: *Would it be OK if I leave …* ではなく、*left* のように過去形にします。一方、*Do you mind if I open …* は現在形が基本です
3. **丁寧にしすぎる**: 友だちに *Would it be OK if I borrowed your pen?* と言うと、距離を感じさせることがあります。関係に合う形を選びましょう
4. **相手の肩書きだけで決めない**: 相手との関係と場面の両方を見ます。初対面でも、カジュアルな場なら *Can I …?* が自然なことがあります
5. **声の調子**: Longman は、*would you mind …?* が、怒りを込めた命令としても使われると注記しています。笑顔で言えば丁寧な依頼に、きつい声だと嫌みに聞こえることもあります

## 今日からの練習

許可を求めたくなる場面は、意外に毎日あります。窓を開ける、席に座る、荷物を置く、電話に出る。そのたびに、頭のなかで5つのどれが合うかを考えてみてください。

覚えるときは、フレーズだけでなく、例文ごとのほうが口から出やすくなります。やり方は「[単語は「例文ごと」覚えよう](/articles/example-sentences)」で紹介しています。「間違えたらどうしよう」と思って声に出せないときは、「[まちがえるのが怖いあなたへ](/articles/mistakes-ok)」や、「[英語の独り言](/articles/self-talk)」の練習が役に立ちます。
