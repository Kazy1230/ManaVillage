子どもの英語が気になるけれど、自分の英語には自信がない。そんな親が、親子で家で英語を始める方法をまとめました。使うのは、**ものの名前、毎日の決まったフレーズ、家事中の独り言**の3つ。教材も、まとまった時間もいりません。

## 親の英語が完璧でなくてもいい？

「自分の英語がまちがっていたら、子どもに悪い影響があるのでは」と心配になりますよね。

この点を調べた研究はあります。ただし注意が必要です。Buac と Kaushanskaya(2023)は、アメリカのスペイン語・英語バイリンガルの幼児について、周りの大人の非ネイティブの英語の入力と、子どもの言語力の関係を調べました。結果は、なまりのある入力は子どもの言語力と逆の関係にあった一方、親の話す英語の文法の複雑さは、子どもの言語力と関係がありませんでした。また、ほとんどの子どもは平均的な言語力で、著者らは、非ネイティブの入力が典型的な発達を妨げるわけではないと述べています。

ただ、この研究は英語が生活言語の環境にいる子どもが対象で、日本の家庭で親が英語を少し足す場面とは条件が違います。そのため、ここから言えるのは「文法の複雑さは言語力と関係がなかった一方、なまりのある入力には逆の関係が見られた」という範囲までです。

実用的には、次のように考えておくと楽です。

- 聞き取りやすく、はっきり言う(早口にしない)
- 自信のない単語は、先に調べてから言う
- 間違えたら「あ、こう言うんだった」と言い直す。その姿も学びの場面になる

## ステップ1:ものの名前を言う

まずは、目に入るものを英語で言います。毎日見るものは、毎日言えるので、自然とくり返しになります。

場所ごとに、最初の5語ほどを決めておくと続けやすいです。

| 場所 | 単語の例 |
|---|---|
| キッチン | fridge(冷蔵庫)、spoon(スプーン)、cup(コップ)、plate(お皿) |
| 洗面所 | toothbrush(歯ブラシ)、towel(タオル)、soap(せっけん) |
| リビング | remote(リモコン)、sofa(ソファ)、curtain(カーテン) |
| 玄関 | shoes(くつ)、umbrella(かさ)、key(かぎ) |

名前だけでなく、短い文にすると、そのまま使える表現になります。

<div class="example"><span class="lbl">EXAMPLE</span><span class="en">It's a <mark class="hl">fridge</mark>! / Where's the <mark class="hl">remote</mark>? / Wash your <mark class="hl">hands</mark>!</span><span class="ja">冷蔵庫だよ！ / リモコンどこ？ / 手を洗って！</span></div>

リモコンがなくなって、家族総出で探す場面は、どの家にもありがちです。そんなときに Where's the remote? と言ってしまえば、探し物が英語の練習に変わります。

わからない単語は、スマホで調べてメモしておきましょう。このやり方は、[英語がひとことも出てこない人のための「独り言」入門](/articles/self-talk-beginners)でも紹介しています。

## ステップ2:毎日の決まったフレーズを言う

慣れてきたら、毎日かならず起きる場面のフレーズを英語にします。ポイントは、**場面と言葉をセットで固定する**ことです。毎日同じ場面で同じ言葉を使うと、その場面が、言葉を思い出すきっかけになります(場面と記憶の関係は[覚えた「場所」と「気持ち」ごと思い出せる？](/articles/context-memory)で紹介しています)。

| 場面 | 英語 |
|---|---|
| 朝起きたとき | Good morning! Did you sleep well? |
| 着替え | Put on your socks. / Are you ready? |
| 朝ごはん | Let's eat! / It's yummy! / Do you want some more? |
| 出かけるとき | Let's go! Do you have everything? |
| 帰宅 | I'm home! / Welcome back! |
| お風呂 | Bath time! / It's hot. / Wash your hair. |
| 片づけ | Clean up time! / Put it back, please. |
| 寝るとき | Brush your teeth. / Good night. Sweet dreams. |

最初から全部はやらなくて大丈夫です。たとえば「朝起きたとき」と「寝るとき」の2つだけ決めて、1週間続けてみる。慣れたら、場面を1つずつ足していきます。

答え方も、子どもが言いやすい短い形にしておくと会話になります。

<div class="example"><span class="lbl">EXAMPLE</span><span class="en">Do you want some more? — <mark class="hl">Yes, please.</mark> / <mark class="hl">No, thank you.</mark></span><span class="ja">おかわりいる？ — うん、お願い。/ ううん、いらない。</span></div>

朝の忙しいときに英語を足すのは大変です。そんなときは、日本語のままで構いません。全部を英語にする必要はなく、**ひとことだけ英語**で十分です。

## ステップ3:家事をしながら独り言を言う

自分がしていることを、そのまま英語でつぶやきます。子どもに向けて言う必要はありません。聞かせるつもりで言うより、自分の練習のつもりで、気楽に言うほうが続きます。

<div class="example"><span class="lbl">EXAMPLE</span><span class="en">I'm <mark class="hl">cooking</mark> curry. It smells good! Oh no, I forgot to buy milk.</span><span class="ja">カレー作ってるよ。いい匂い！ あ、牛乳買い忘れた。</span></div>

家事ごとに、使える形を用意しておきます。

| 家事 | つぶやき |
|---|---|
| 洗濯 | I'm doing the laundry. / This is still wet. / Let's hang it up. |
| 料理 | I'm chopping onions. / It's boiling. / It needs more salt. |
| 掃除 | I'm vacuuming. / Who left this here? |
| 買い物 | We need eggs. / Is this on sale? |

ポイントは、**今やっていること**を、**I'm ~ing** で言うことです。いま目の前で起きていることなので、単語を思い出しやすく、場面とセットで頭に残ります。

つぶやきが「ひとこと」で終わってしまうのも、最初は普通です。そのときは、感想を1つ足してみてください。

<div class="example"><span class="lbl">EXAMPLE</span><span class="en">I'm folding the towels. <mark class="hl">They're so soft.</mark></span><span class="ja">タオルをたたんでるよ。ふわふわだね。</span></div>

「言葉が出てこない」「文にならない」という人は、[独り言のやり方](/articles/self-talk)もあわせて読んでみてください。

## 子どもの反応が薄いときは

せっかく英語で話しかけても、「なんで英語？」「やだ」と言われることもあります。そんなときは、無理に続けなくて大丈夫です。

- 遊びにする(「冷蔵庫はどれだ？ Fridge, fridge!」とクイズにする)
- 場面を減らす(朝か夜のどちらか1つだけにする)
- 子どもには言わせない。親が言うだけにする

強制すると、英語が「やらされること」になってしまいかねません。親のほうが楽しんで、子どもがのってきたら、ちょっと広げる。その順番がいいと思います。

## 親自身の英語学習にもなる

この方法は、子どものためだけではありません。家事や育児のすき間が、そのまま**親自身の英語の練習時間**になります。

本格的に英語をやり直したくなったら、[40代・50代からの英語やり直し](/articles/adults-restart)や、[忙しい社会人のための「スキマ5分」英語メニュー](/articles/5-minute-gaps)も読んでみてください。

## 今日からやること

まず、家の中で**1つだけ**、英語にする場面を選びましょう。おすすめは、毎日ある「寝る前のひとこと」です。Good night. Sweet dreams. の2文から始めて、慣れたら朝の Good morning! を足します。
