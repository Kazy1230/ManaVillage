海外旅行初日、はじめてのカフェ。緊張しながらカウンターで注文します。

*"I want coffee."*

ちゃんと通じます。コーヒーも出てきます。でも、英語話者の耳には「コーヒーほしい！」と子どもがねだっているような、ちょっと直球すぎる響きに聞こえることがあります。

![左は「I want coffee.」と言う無表情な客と汗をかく店員でバツ印。右は「I'd like a coffee, please.」と言う笑顔の客とハートを浮かべる店員でマル印の絵](/articles/would-like/1.svg)

## 結論：お店と仕事では would like

- ==want==：「ほしい」「したい」を、そのまま言う直球の言い方
- ==would like==：同じ意味を、ひかえめに伝えるていねいな言い方

would like は会話では ==I'd like== と縮めて言うのがふつうです。さっきの注文はこうなります。

<div class="example"><span class="lbl">EXAMPLE</span><span class="en"><mark class="hl">I'd like</mark> a coffee, please.</span><span class="ja">コーヒーをひとつお願いします。</span></div>

## なぜ would をつけるとていねいになるの？

would は「もしよければ」という、一歩引いた気持ちを表す言葉です。「コーヒーがほしい」をそのまま言うのではなく、「（もしよければ）コーヒーをいただきたいのですが」と、クッションを入れた感じになります。

日本語でも「ほしい」より「いただけますか」のほうがていねいに聞こえますよね。それと同じです。

## 形は2つだけ：名詞か、to＋動詞か

would like のあとに来るのは、次のどちらかです。

- ほしいもの（名詞）→ ==I'd like== + もの
- したいこと（動詞）→ ==I'd like to== + 動詞

<div class="example"><span class="lbl">EXAMPLE</span><span class="en"><mark class="hl">I'd like</mark> a window seat, please.</span><span class="ja">窓側の席をお願いします。</span></div>

<div class="example"><span class="lbl">EXAMPLE</span><span class="en"><mark class="hl">I'd like to</mark> book a table for two at 7.</span><span class="ja">7時に2名で予約したいのですが。</span></div>

## 職場では「相手にしてほしいこと」にも使う

仕事でよく使うのが、相手にお願いするときの ==I'd like you to...== です。

<div class="example"><span class="lbl">EXAMPLE</span><span class="en"><mark class="hl">I'd like you to</mark> check this draft before the meeting.</span><span class="ja">会議の前に、この下書きを確認してもらえますか。</span></div>

同じことを *"I want you to check this."* と言うと、「これチェックして」と上から指示しているような響きになりがちです。上司や取引先に対しては would like を使いましょう。

## 聞くときは Would you like...?

相手に何かをすすめるときは、疑問文にします。

<div class="example"><span class="lbl">EXAMPLE</span><span class="en"><mark class="hl">Would you like</mark> some tea?</span><span class="ja">お茶はいかがですか？</span></div>

家に来た友だちや、職場のお客さんに使えます。

## want がぴったりな場面もある

want が悪い言葉なわけではありません。家族や仲のいい友だちとの会話では、むしろ want のほうが自然です。

<div class="example"><span class="lbl">EXAMPLE</span><span class="en">I <mark class="hl">want</mark> ramen tonight!</span><span class="ja">今夜はラーメンが食べたい！</span></div>

ここで *"I'd like ramen tonight."* と言うと、急にかしこまって、ちょっと距離を感じさせてしまいます。**相手との距離で選ぶ**のがポイントです。

## よくある間違い

<div class="example ng"><span class="lbl">NG</span><span class="en">I'd like to coffee.</span><span class="ja">coffee はもの（名詞）なので to はいりません。I'd like a coffee. が正解です。to を使うのは、あとに動詞が来るときだけです。</span></div>

## まとめ

- ==want== は直球、==would like== はひかえめでていねい
- お店・仕事・目上の人には ==I'd like==
- もの（名詞）なら I'd like ___、したいこと（動詞）なら ==I'd like to== ___
- 相手へのお願いは ==I'd like you to...==、すすめるときは ==Would you like...?==
- 家族や友だちには want でOK

あなたがよく行くお店で、いつも頼むものは何ですか？ *"I'd like ___, please."* の形でコメントしてみてください。
