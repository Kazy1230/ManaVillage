単語帳も文法書も進めたのに、いざ話そうとすると英語が出てこない。そんなときに効くのが、通勤・通学中にできる英語の独り言です。

この記事では、独り言のやり方を具体的にまとめます。なぜ独り言が話す力につながるのか、朝・電車・店・帰り道の場面別フレーズ、3つの段階の進め方、言えなかった表現のメモの回し方、声を出せない場所での工夫の順に進みます。まったく何も出てこない人は、先に[英語がひとことも出てこない人のための「独り言」入門](/articles/self-talk-beginners)から始めてください。この記事は、単語やひとことなら言える人の、次の一歩です。

## 独り言が、話す力につながる理由

単語帳や文法書で覚えた英語は、「○ページの例文」「○番の単語」という形でしまわれがちです。ところが会話で必要なのは、「この場面では、これを言う」という形の引き出しです。

たとえば、スマホのホーム画面を思い浮かべてください。アプリが入っていても、どこにあるか分からなければ、急いでいるときに開けません。よく使うアプリを、よく使う場所に置いておくのと同じで、英語も場面に置いておくと取り出しやすくなります。

独り言は、その置き場所を作る作業です。暑い日に *"It's so hot today."* と言えば、英語と「暑い」という実感が組になります。次に暑い日が来たとき、その実感が、英語を取り出すきっかけになってくれます。

<div class="voice"><span class="lbl">運営者の意見</span><p>運営者は、移動中に知っている英語を口ずさむ練習の次の段階が、通勤・通学中の独り言だと考えています。目の前の情景や、そのときの感情と英語が結びつくので、スピーキングで引き出しやすくなる、というのが理由です。</p></div>

### 研究では、どこまで言えるのか

場面と記憶の関係では、ダイバーが陸と水中で単語を覚える1975年の実験が有名です。ただ、2021年にMurreが同じ手順で再現を試みたところ、覚えた場所と同じ場所で思い出したほうがよい、という結果は出ませんでした。

つまり「場面と一緒に覚えれば、必ず思い出しやすくなる」とまでは言えません。独り言が効く理由として、この研究を根拠にするのは控えておきます。詳しい経緯は、[覚えた「場所」と「気持ち」ごと思い出せる？](/articles/context-memory)にまとめました。

一方で、声を出すことには別の研究があります。MacLeodらの2010年の実験では、単語を声に出して読んだほうが、黙って読むより、あとで思い出しやすくなりました。声に出さず、口だけ動かした場合にも、同じ傾向が見られています。ただし、これは単語のリストを使った実験で、独り言そのものを調べたものではありません。「声を出すと記憶に残りやすいことがある」と、ゆるく受け取ってください。

## 場面別:そのまま使える独り言

まずは、毎日の流れに沿って、言いやすい一言を決めておきます。朝の通勤路で、電車で、お店で、帰り道で。場面が決まっていれば、「何を言おう」と迷う時間が減ります。

### 朝

<div class="example"><span class="lbl">EXAMPLE</span><span class="en"><mark class="hl">I'm so sleepy.</mark> I want to go back to bed.</span><span class="ja">めっちゃ眠い。もう一回寝たい。</span></div>

- *"It's cold this morning."*(今朝は寒いな)
- *"I have a meeting at ten."*(10時に会議がある)
- *"I forgot my umbrella."*(傘を忘れた)

### 電車・バス

<div class="example"><span class="lbl">EXAMPLE</span><span class="en">Oh no, <mark class="hl">the train is late again.</mark> I'm going to be late for work.</span><span class="ja">うわ、また電車遅れてる。会社に遅刻しそう。</span></div>

- *"It's so crowded."*(混んでるなあ)
- *"I got a seat!"*(座れた!)
- *"This is my stop."*(次で降りる)

### 店(コンビニ・ランチ)

<div class="example"><span class="lbl">EXAMPLE</span><span class="en"><mark class="hl">I'm starving.</mark> What should I eat for lunch?</span><span class="ja">お腹ぺこぺこ。お昼何食べよう?</span></div>

- *"I need a cold drink."*(冷たい飲み物がほしい)
- *"The line is so long."*(列がすごく長い)
- *"I'll get this one."*(これにしよう)

### 帰り道

<div class="example"><span class="lbl">EXAMPLE</span><span class="en"><mark class="hl">Finally, it's Friday!</mark> I'm going to watch a movie tonight.</span><span class="ja">やっと金曜日だ!今夜は映画を見よう。</span></div>

- *"What a long day."*(長い一日だった)
- *"I'm so tired. I'll take a bath."*(疲れた。お風呂に入ろう)
- *"I can't wait for the weekend."*(週末が待ちきれない)

全部を覚える必要はありません。各場面から、いちばん言いそうな一言を1つ選んで、1週間ほど同じ場面で言い続けてみてください。言いそうにないものは、飛ばして大丈夫です。

## 3つの段階で、少しずつ長くする

いきなり長い文を作ろうとすると、手が止まります。次の3段階で、少しずつ伸ばします。

### 段階1:目に入ったものを言う

<div class="example"><span class="lbl">EXAMPLE</span><span class="en">A convenience store. A big dog. So many people.</span><span class="ja">コンビニ。大きい犬。人が多いなあ。</span></div>

名詞だけで構いません。目に入ったものに、英語の名前を付けていく段階です。

### 段階2:気持ちを足す

<div class="example"><span class="lbl">EXAMPLE</span><span class="en">A big dog. <mark class="hl">So cute!</mark> / A long line. <mark class="hl">Ugh.</mark></span><span class="ja">大きい犬。かわいい! / 長い列。うわぁ。</span></div>

そのものに、好き・嫌い・眠い・うれしいといった一言を足します。`I'm so ...` と `It's so ...` だけでも、かなりの気持ちを言えます。

### 段階3:予定や考えごとを言う

<div class="example"><span class="lbl">EXAMPLE</span><span class="en">I'm so tired. <mark class="hl">I'm going to</mark> go to bed early tonight.</span><span class="ja">疲れた。今夜は早く寝よう。</span></div>

いまの気持ちから一歩進めて、これからのことや、頭の中の考えごとを言う段階です。`I'm going to ...`(〜しよう)、`I should ...`(〜したほうがいいな)、`Maybe I'll ...`(〜してみようかな)が使いやすい型です。

3段階は、上から順に「卒業」するものではありません。今日は段階1だけ、今日は段階3まで、と、その日の余裕で選べば十分です。

## 言えなかった表現は、こう回す

独り言を続けると、言いたいのに言えない表現に、必ず出会います。たとえば、雨上がりの道で「水たまりを避けた」と言いたいのに、単語が出てこない。そんなことは、ありますよね。

それは失敗ではなく、次に覚える表現が見つかったということです。

1. その場では、単語だけ言うか、日本語のまま飛ばして、先へ進む
2. 歩きながらは調べずに、スマホのメモに日本語で書き残す(「水たまりを避ける」など)
3. 昼休みや帰りの電車で、まとめて英語を調べて、メモに足す
4. 翌日、同じ場面で、その英語を使ってみる

<div class="example"><span class="lbl">MEMO</span><span class="en">avoid a puddle / I almost stepped in a puddle.</span><span class="ja">水たまりをよける / 水たまりを踏みそうになった</span></div>

歩きながら調べないのは、そのたびに止まって、独り言が途切れるからです。1と2で「言えなかった」という事実だけを残して、調べるのは後にします。

<div class="voice"><span class="lbl">運営者の体験</span><p>運営者は、英語が出てこなかった頃、言えなかった表現をいちいち調べてメモし、それを繰り返すうちに言えるようになったといいます。</p></div>

メモは、増やしすぎないのがコツです。1日に調べるのは、3つまでで十分です。同じ道を毎日通るなら、同じ場面で何度も使えるので、数が少なくても定着します。

## 声に出せない場所での工夫

満員電車やオフィス街の歩道で、英語をつぶやくのは難しいものです。場所ごとに、やり方を変えます。

- **満員電車、人の多い道**: 頭の中で言う。音のない独り言でも、場面と英語を結びつける練習にはなります
- **少し空いた電車、駅のホーム**: 口を小さく動かす。声は出さず、形だけ作る
- **人通りの少ない道**: 小さな声で言う。口と耳も使えるので、頭の中だけのときより、言う感覚がつかめます
- **イヤホンをしているとき**: 通話中のふりをして、ふつうの音量で言う、という人もいますが、周りが気になるなら無理は禁物です

研究で見たとおり、口を動かすだけでも効果が見られた実験はあります。ただし、単語を覚える実験での話です。頭の中だけの独り言が効かない、という意味ではありません。続けやすい形を選んでください。

もう一つ、間違いが気になって言葉が止まってしまう人もいます。独り言は、誰にも聞かれないので、文法が変でも、単語が違っても問題ありません。その気持ちの持ち方は、[まちがえるのが怖いあなたへ。独り言なら、誰にも聞かれない](/articles/mistakes-ok)で詳しく書いています。

## 口ずさみの次に、独り言

知っている英語を、そのまま口ずさむ練習は、[聞き流すだけで英語は話せるようにならない。でも「口ずさむ」なら](/articles/mumble-commute)で紹介しました。口ずさみは、覚えた英語をそのまま言う練習。独り言は、いまの自分の状況を、自分の言葉で言う練習です。

口ずさみで口が慣れてきたら、1日1場面だけ、独り言を混ぜてみてください。最初は、朝の一言だけでも十分です。

## まとめ

今日の通勤・通学で試すなら、次の3つだけです。

- 朝・電車・店・帰り道から、場面を1つ選ぶ
- その場面で言いそうな一言を、1つ決めておく(上のフレーズから選んでOK)
- 言えなかったことを、スマホに日本語でメモしておく

あなたは今朝、何と言いたかったですか? 言えなかった表現でも、言えた一言でも、コメント欄に1文書いてみてください。
