# 哲学を学ぶ(日本語で書く)の記事制作ルール

問いの立て方や、考えの筋道を、身近な例で解説する記事(`/philosophy/articles/...`)のルール。
**流れと役割分担は `planning/common.md`**(2-1c, 2-1d の書き方も同じ)。記事の作業をするときは、`common.md` とこの文書の2つを読む。

## 1. 読者と、基本の方針

- 読者: 哲学を初めて読む人(初心者)。むずかしい用語を覚える記事ではなく、「考えるための道具」として見せる
- 著者: **Kaz**(`author: kaz`)。白河雪菜は、英語学習・日本語学習の記事だけで使う
- type: 基本は **general**。体験談は、記録があるものだけ(`common.md` 2-1b)
- 分量の目安: 2,500〜4,500字
- 見出し・導入・口調・改行は `common.md` 2-1d。導入は、**思考実験や問い**から入ると読みやすい。最後に、読者が自分で考える問いを置いてよい

## 2. 事実の根拠

- **二次資料は、信頼できる百科事典**(Stanford Encyclopedia of Philosophy、Internet Encyclopedia of Philosophy など)で確かめる。原典の翻訳が確認できるなら、そちらも使う。確認できた内容と URL を `sources` に書く
- **解釈が分かれる所は、「分かれている」と書く**。一つの解釈を、定説のように書かない
- 年号、著作名、人物の生没年は、出典で確認する
- 引用は短くする。**著作権のある翻訳をそのまま長く引用しない**(要約する)
- 根拠にしない: 他の解説ブログ、Q&A サイト、AI の答え
- 「〜は〜と言った」と断定する前に、**その言葉が、どの著作のどこに出るか**を確かめる

## 3. ハブとタグ(固定の一覧。足したいときは Kaz に確認)

- **ハブ**(記事ごとに1つ): `古代哲学`、`近代哲学`、`現代哲学`、`倫理学`、`思考実験`、`考え方の道具`
- **タグ**(3〜5個): 人名(`デカルト`、`ソクラテス` など)、ハブ名、`入門`、`思考実験`、`論理`

## 4. 確認で足す項目(`manavillage-checker`)

- 人物・著作・年号・用語が、出典と合っているか
- **解釈が分かれる所を、一つに決めつけていないか**。「〜と言われる」「〜と解釈される」の根拠があるか
- 要約が、原典の主張を歪めていないか。現代の問題に当てはめる所は、「当てはめ」と分かるか
- 引用が短いか。長い引用がないか

## 5. frontmatter

`planning/workflow.md` 6章と同じ。`keyword` は、カードに「この記事の問い」として出る、短い問い(例: 「疑っても、疑えないもの」)。

## 6. 置き場所

| 項目 | 場所 |
|---|---|
| 記事 | `web/content/philosophy/articles/<slug>.md` |
| テーマ管理表(IDは `P-xxxx`) | `web/content/planning/philosophy/topic-map.md`(次の候補も、ここ) |
| イラスト | `web/content/illustrations/<slug>/` |
