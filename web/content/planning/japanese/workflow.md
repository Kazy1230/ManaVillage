# 日本語学習(英語で書く)の記事制作ルール

英語話者に向けて、日本語の文法・助詞・似た言葉・丁寧さ・フレーズ・学習法を英語で解説する記事(`/en/japanese/...`)のルール。
**流れと役割分担(Kaz が書く、Claude は提案・確認・イラスト・公開)は `planning/common.md`**。記事の作業をするときは、`common.md` とこの文書の2つを読む。

**著者は二人**(2026-10-04 決定): **Kaz が英語で書く記事**と、**白河雪菜の記事**(Claude が雪菜になりきって英語で書く。`common.md` 5章、`characters/shirakawa-yukina/profile.md`)。Kaz の記事では、Claude は英語の訂正案を出さず、不自然な所を指摘するだけにする。雪菜の記事は、Claude が書いた文章なので、指摘を受けて Claude が直す。

---

## 0. 読者

- 日本語を学んでいる、英語で読める人。**対象レベルは絞らない**。記事ごとに、初級・中級・上級のどれ向けかを決める
- 同じテーマでも、レベルによって検索の言葉と知りたいことが違うなら、レベル別に記事を分けてよい(`common.md` 1章の「重複の判定」)。レベル別の記事どうしはリンクする
- レベルは `targetReader` に書き、タグにも `Beginner` / `Intermediate` / `Advanced` のどれかを入れる。例文の漢字や語彙は、そのレベルに合わせる
- 検索は英語で行われる(例: `wa vs ga`、`te shimau meaning`)。主キーワードも英語の検索語

| 項目 | 日本語学習 |

| 記事のフォルダ | `content/japanese/articles/` |

| 分量の目安 | 1,200〜2,500語(内容が足りなければ、短くてよい) |

## 2. 記事の種類と、答えること

**決まった構成(型)は使わない**。下の「答えること」を押さえれば、見出しの順番や見せ方は、テーマごとに自由。同じ科目の直近5本と、見出しの流れが似すぎないようにする。

| 種類 | 例 | 記事が答えること |
|---|---|---|
| 助詞 | は vs が、に vs で | それぞれの働き / どちらを使うかの決め方 / よくある間違い |
| 文法の形 | 〜てしまう、〜ている | 意味(複数あれば全部)/ 作り方(接続)/ 使う場面と使わない場面 |
| 似た言葉(① 似た単語) | 見る / 見える / 眺める | それぞれの意味と使う場面 / 置き換えると変になる例 |
| 機能の言い換え(②) | 依頼の言い方、謝り方 | その目的を果たす言い方の一覧 / くだけた〜丁寧の段階と、使う相手・場面 |
| 丁寧さ・場面(③) | です/ます と普通形、敬語 | 誰に・どんな場面で使うか / 間違えたときに相手がどう感じるか |
| 母語からのずれ(④) | "I’m sorry" と すみません | 英語の言葉をそのまま訳すと何がずれるか / 代わりの言い方 |
| 決まった言い方・場面のフレーズ | いただきます、お店で | 意味と、使う場面 / 返し方 |
| 学習法 | 漢字の覚え方、JLPT の勉強 | 具体的な手順 / つまずく所と対処 |

- 1記事1テーマ。広い記事(「助詞のまとめ」など)は、個別の記事ができてから、ハブ記事として
- 似た言葉・フレーズは、「機能のハブ → 2〜3語の比較 → 1つの言い方」のどの記事かをはっきりさせる(`common.md` 1章)

## 3. 内容のルール

- **日本語の例文は、自然な日本語だけ**。教科書的すぎて、実際には言わない文は避ける。1つの例文で学んでほしいことは1つ。場面は読者が想像しやすい日常
- 間違い例(NG)は、**はっきり誤りと言えるもの**だけ。「間違いではないが不自然」は NG にせず、本文で説明する
- **文法の説明は、ネットで原文を確認できる信頼できる資料で裏付ける**。Claude が提案のときに調べ、確認できた内容と URL を示す。確認できない説明は書かない
  - 使ってよい: 国語辞典(コトバンクの『デジタル大辞泉』など)、文化庁の資料(『敬語の指針』など)、国立国語研究所の資料、JLPT の公式サイト(レベルの説明)、国際交流基金の日本語教育の資料(『日本語教育通信』など)
  - 根拠にしない: 他の学習ブログ、Q&A サイト、掲示板、AI の答え
- **例え話**は、英語圏の読者にも通じる日常を使う。「日本人は〜」のような、国や文化の決めつけをしない
- **JLPT**: JLPT は、レベルごとの単語・漢字・文法の公式リストを公開していない(JLPT 公式サイトの FAQ。https://www.jlpt.jp/e/faq/ で確認済み)。タグは「そのレベルでよく学ぶ」という目安。本文で「N4 の公式文法」とは書かず、`commonly studied around N4` のように書く
- イラスト: サイト共通の画風。和の小物(鳥居、桜、のれん、茶碗など)を入れてよい。**絵の中の日本語には、ルビを付けない**。`coreIllustrationAlt` は英語で書く

## 4. 提案で確認すること(Claude)

`common.md` 2-1 に加えて:

- 記事のレベルを決めて、テーマがそのレベルに合うか
- 英語で検索して、英語圏の上位記事にない情報の候補を示す
- 文法の説明の根拠になる資料(3章)を、実際に開いて確認し、確認できた内容を示す
- 例文の候補(自然な日本語)を、レベルに合った語彙と漢字で数個示す(Kaz は、そのまま使っても、自分で作ってもよい)
- 似た言葉・フレーズの記事なら、層(①〜④)と、「機能のハブ/比較/1つの言い方」のどれかを決める

## 5. 確認で足す項目(Claude)

`common.md` 2-3 に加えて:

- 日本語の例文が自然か(実際に言うか、場面に合うか)。NG 例が本当に誤りか
- 文法の説明が正しいか。例外があるのに言い切っていないか(「always」「never」)。説明が出典で裏付けられているか
- 例文の英訳が、日本語と同じ意味か(ニュアンスを足したり落としたりしていないか)
- ローマ字の表記がルール(1章)どおりか
- 英語が不自然な所(**直した文は出さず、どこが不自然かだけ**を指摘する)。アメリカ英語のつづりか
- 例え話が、英語圏の読者にも通じるか。国や文化の決めつけがないか
- 2章の「答えること」を、押さえているか
- JLPT タグを付けているなら、本文で「公式の N4 文法」のように書いていないか
- 小テストがあるなら、正解が1つに決まるか

## 6. 機械チェック(`check-article.mjs` が見る項目)

- frontmatter: 必須の項目、slug とファイル名の一致、status の値、公開済みなら publishedAt。**type は general**
- **ルビ**: title、description、本文、phrases の漢字に、すべて読みがあるか
- **タグ**: 10章の一覧にあるものだけ。3〜5個。レベルのタグがちょうど1つ。JLPT のタグは0〜1つ
- **ハブ**: Particles / Grammar / Synonyms / Politeness / Phrases のどれか
- description: 英語で110〜160文字(外れると「要確認」)
- 見出しの階層、画像の alt とファイル。サムネ(`core.webp`)を本文に書いていたら不合格
- 内部リンク(`/en/japanese/articles/<slug>`)と related が公開済みか(本数の不足は、公開済み記事が3本未満のあいだ「要確認」)
- 主キーワードの語が、title と導入にすべて入っているか(大文字小文字は区別しない)
- 本文が800語未満なら「要確認」。slug が、ほかの科目の記事と重複していないか
- `planning/japanese/topic-map.md` に行があり、主キーワードが一致しているか

## 7. frontmatter(Claude が組み立てる)

```yaml
---
title: "…"                 # Kaz が選んだ題名。漢字があればルビの記法
description: ""            # 英語で110〜160文字。Claude が案を出し、Kaz が決める
slug: ""                   # 英語学習の記事と重複させない
type: general
status: draft
publishedAt: ""
updatedAt: ""
primaryKeyword: ""         # 英語の検索語
searchIntent: ""
targetReader: ""           # レベルも書く
hub: ""                    # 10章の一覧から
tags: []                   # 3〜5個。10章の一覧から
coreIllustration: core.webp
coreIllustrationAlt: ""    # 英語で
related: []
sources: []                # 確認した辞書・文法書・公的な資料
materialsUsed: []          # 日本語学習では使わない
keyword: ""                # カードに大きく出る短い言葉
phrases:                   # 任意。最新記事のときトップのヒーローで切り替わる例文(2〜5個)
  - jp: "{私|わたし}は{学生|がくせい}です。"
    romaji: "Watashi wa gakusei desu."
    en: "I’m a student."
---
```

## 8. Kaz の書き方の約束(これだけ守れば、あとは自由)

Kaz は、ふつうの Markdown で、**英語で**書く。日本語の例は、ふつうの漢字かな交じりで書いてよい(ルビは付けない)。Claude が、保存するときに機械的に変換する(英語の文章は変えない。変えた所は報告する)。

- 見出し: `##` から始める
- **例文**: 引用(`> `)で3行。日本語、ローマ字、英訳の順 → 3段の例文ボックスに変換される。間違い例は、日本語の行の前に `NG: `、正しい例は `OK: ` を付ける
- **例え話**: 段落の前に `【例え話】` と書く → 例え話の囲みに変換される
- **ルビ**: Claude が、漢字すべてに `{漢字|かんじ}` の形で読みを付ける(文中の読みで)。**付けた読みの一覧を報告するので、Kaz が確認する**
- 蛍光ペン: `==語句==`。図が欲しい所: `[図: こんな図が欲しい]`
- 内部リンク: `[タイトル](/en/japanese/articles/<slug>)`(公開済みの記事だけ)

## 9. Kaz が決めたこと(まとめ)

対象レベルは絞らず、記事ごとに決める / 分量は1,200〜2,500語 / 絵の中の日本語にルビは付けない / ローマ字の長音は記号あり(`gakkō`) / 英語のつづりはアメリカ英語 / 文法の説明は、ネットで原文を確認できる信頼できる資料で裏付ける(国際交流基金の資料を含む) / 決まった構成(型)は使わない / **記事は Kaz が英語で書く(2026-10-04)** / 提案は、Kaz が言ったときに出す

## 10. ハブとタグ(固定の一覧。Kaz 決定)

ここにないハブやタグは作らない。足したいときは Kaz に確認する。

- **ハブ(大分類。記事ごとに1つ)**: `Particles`(助詞)、`Grammar`(文法の形)、`Synonyms`(似た言葉)、`Politeness`(丁寧さ・敬語)、`Phrases`(決まった言い方)
- **タグ(記事ごとに3〜5個)**
  - ハブ: `Particles` `Grammar` `Synonyms` `Politeness` `Phrases`
  - レベル(1つ): `Beginner` `Intermediate` `Advanced`
  - JLPT(0〜1つ): `N5` `N4` `N3` `N2` `N1`
  - そのほか: `Verbs` `Adjectives` `Conversation` `Business`
- JLPT タグは、迷うとき、レベルに関係しない記事には付けない。対応の目安: N5・N4 = Beginner、N3 = Intermediate、N2・N1 = Advanced

## 11. 新しい流れと書き方(2026-10-05 から)

`common.md` の 2-0(インタビュー → 記事化 → 面白くする編集者 → 承認 → 公開)と 2-1d(書き方)に従う。日本語学習(英語で書く)で特に守ること:

- **インタビューは、日本語で行う。Kaz の答えは、英語の記事に、記録の範囲で使う**。聞くこと: 日本語を学ぶ人(英語話者)が、どこで引っかかると感じるか。日本語を教えた・伝えた体験。英語で説明するときに、使うたとえ
- **AI 臭は、英語でも消す**。次のような英語の癖を使わない: "Let's dive in" / "Let's break it down" / "In this article, we will..." / "It's important to note that..." / "Here's the thing" / "Whether you're a beginner or an advanced learner..." / "In conclusion" / "So, what's the takeaway?" / 毎回の "Ready to try?" で終える締め。見出しも、"Understanding X" "A Comprehensive Guide to X" のようなラベルにしない。まとめの節の見出しは "Summary"(2-1d の「まとめ」に当たる)
- **分かりやすい説明の型**(2-1d)を、英語で使う: 身近な一言で理由を言い切る / "X, but not Y" の対比 / わざと変な日本語の文で、ずれを体感させる(例: 「リンゴを立つ」のような)/ 英語の感覚から日本語へつなぐ
- ルビ、ローマ字、アメリカ英語、レベルのタグ、固定のタグ・ハブは、この文書の1〜10章のとおり(変えない)
