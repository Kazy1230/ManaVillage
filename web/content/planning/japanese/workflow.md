# 日本語学習(Learn Japanese)記事制作ワークフロー

> **状態: 確定(2026-10-02、Kaz が全項目を決定)。** この手順で記事を作ってよい。最初の記事は `wa-vs-ga`(テスト用の下書きを仕上げる)。

英語話者に向けて、日本語の文法と、似た言葉の使い分けを英語で解説する記事(`/en/japanese/...`)の作り方。
基本は英語学習のワークフロー(`web/content/planning/workflow.md`)と同じ。この文書には、**違う所と、足す所**だけを書く。書いていないことは、英語学習のワークフローに従う。

---

## 0. 目的と読者

- 読者: 日本語を学んでいる、英語で読める人。**対象レベルは絞らない**。記事ごとに、初級・中級・上級のどれ向けかを決めて、レベルに合わせて書く(Kaz 決定)
  - 同じテーマでも、レベルによって検索の言葉と知りたいことが違うなら、レベル別に記事を分けてよい(英語学習の「重複の判定基準」と同じ考え方)。レベル別の記事どうしはリンクする
  - レベルは `targetReader` に書き、タグにも `Beginner` / `Intermediate` / `Advanced` のどれかを入れる
  - 例文の漢字や語彙は、そのレベルに合わせる(初級向けに難しい語彙を混ぜない)
- 記事が答えること: 「この2つの違いは何か」「この形はいつ使うか」「なぜこれは間違いか」
- 価値の出し方: 教科書の説明の言い換えではなく、**身近な例え話**と、**使う場面が浮かぶ例文**と、**学習者が実際にやる間違い**で、腹落ちさせる
- 検索は英語で行われる(例: `wa vs ga`、`difference between miru and mieru`、`te shimau meaning`)。主キーワードも英語で決める

## 2. 記事の種類

| 種類 | 例 | 構成の目安 |
|---|---|---|
| 助詞 | は vs が、に vs で | 30秒の要点 → 例え話 → 形ごとの例文 → よくある間違い → 比べる表 → 練習 |
| 似た言葉(類義語) | 見る / 見える / 眺める | 30秒の要点 → 比べる表 → 1語ずつ例文 → 置き換えると変になる例 → 練習 |
| 文法の形 | 〜てしまう、〜ている | 30秒の要点 → 形の作り方 → 意味ごとの例文 → 間違い → 練習 |
| 丁寧さ | です/ます と普通形、敬語 | 30秒の要点 → 場面の表 → 同じ内容を丁寧さ別に → 間違えたときの影響 → 練習 |
| 決まった言い方 | すみません と ごめんなさい | 30秒の要点 → 場面別の例 → 言い換え → 練習 |

- **1記事1テーマ**。「助詞のまとめ」のような広い記事は、ハブ記事として、個別の記事ができてから作る

## 3. 書き方

### 英語の文章

- やさしい英語で、短い文で書く。文法用語を使うときは、最初に一言で説明する(例: `particle — a small word that shows the role of the word before it`)
- つづりは **アメリカ英語**にそろえる(Kaz 決定。例: color、favorite、practice、realize)
- 説教にならず、親しみやすく。導入は短く、最初の数行で何が分かるかを示す(英語学習と同じ)

### 日本語の例文

- **自然な日本語だけ**を書く。教科書的すぎて、実際には言わない文は避ける
- 1つの例文に、学んでほしいことは1つ。ほかの難しい文法や、むずかしい漢字を混ぜない
- 例文の場面は、読者が想像しやすい日常(学校、仕事、買い物、友達、家族、旅行)
- 間違い例(NG)は、**はっきり誤りと言えるもの**だけ。「間違いではないが不自然」は NG にせず、本文で説明する
- 文法の説明が正しいかは、**ネットで原文を確認できる、信頼できる資料**で確かめ、`sources` に書く。確認できない説明は書かない(英語学習の「研究・統計」と同じ扱い。Kaz 決定)
  - 使ってよい: 国語辞典(コトバンクに載っている『デジタル大辞泉』など)、文化庁の資料(敬語は『敬語の指針』)、国立国語研究所の資料、JLPT の公式サイト(レベルの説明)
  - 根拠にしない: 他の学習ブログ、Q&A サイト、掲示板、AI の答え。テーマや「学習者がどこでつまずくか」を調べるのには使ってよい

### ルビ(ふりがな)

- 本文、title、description、例文(phrases を含む)の **漢字すべて**に、記法 `{漢字|かんじ}` で読みを付ける
- 読みは、その文での読み方にする(例: `{今日|きょう}`、`{明日|あした}`)。熟語は熟語ごとに付ける
- `<ruby>` タグを直接書かない(記法にそろえる)
- 画面では最初から表示し、読者が記事ページの切り替えで消せる

### ローマ字

- **修正ヘボン式**で書く。助詞の は・を・へ は、発音どおり `wa`・`o`・`e`
- 長音は、**長音記号(マクロン)を使う**(Kaz 決定)。例: `gakkō`(学校)、`Tōkyō`、`kūkō`(空港)、`okāsan`(お母さん)、`onēsan`(お姉さん)
  - おう・おお → `ō`、うう → `ū`、ああ → `ā`、ええ → `ē`
  - いい は `ii`(例: `oishii`)、えい は `ei`(例: `gakusei`、`sensei`)のまま書く
  - 外来語の長音(ー)も記号で書く(例: `kōhī`)
- 例文の下に必ず付ける。本文中で日本語の言葉を出すときは、初出だけ `は (wa)` のように付ける

### 部品(記法)

```html
<div class="points"><span class="lbl">IN 30 SECONDS</span>

- 要点を3つまで

</div>

<div class="analogy"><span class="lbl">THINK OF IT LIKE THIS</span><p>例え話。最後に「たとえであって、すべての場合のルールではない」ことを一言そえる</p></div>

<div class="example"><span class="lbl">EXAMPLE</span><span class="jpx">{私|わたし}<mark>は</mark>{学生|がくせい}です。</span><span class="ro">Watashi wa gakusei desu.</span><span class="tr">I’m a student.</span></div>

<div class="ex-pair">  <!-- 2つ並べる(質問と答え、NG と OK) -->
<div class="example ng"><span class="lbl">NG</span>…<span class="why">なぜだめか(1文)</span></div>
<div class="example ok"><span class="lbl">OK</span>…</div>
</div>
```

- 比べる表は、Markdown の表で書く(サイトの表の見た目になる)
- 蛍光ペン `==…==` は、英語学習と同じ

### 例え話と小ネタ

- 英語学習のワークフロー 3-4 のルールに従う。加えて:
  - 例え話は、**英語圏の読者にも通じる日常**を使う(日本だけの習慣を前提にしない)
  - 「日本人は〜」「外国人は〜」のような、国や文化の決めつけをしない
  - 日本の文化や習慣を紹介するときは、事実として確認できることだけ書く

### イラスト

- 英語学習と同じ画風(白い背景、ゆるいクレヨンの絵)。和の小物(鳥居、桜、のれん、茶碗など。`doodle.mjs` の `torii`、`sakura`)を入れてよい
- **絵の中の日本語には、ルビを付けない**(Kaz 決定)。代わりに `coreIllustrationAlt` に英語で説明を書く

## 4. 流れ

英語学習のワークフロー 3章と同じ順番。違いだけ:

1. **テーマ選定(週1)**: `planning/japanese/topic-map.md` の `idea` の行から選び、企画カードを作る(`planning/japanese/cards/`)。主キーワードは英語の検索語
2. **Kaz の承認**
3. **アウトライン**(`planning/japanese/outlines/`)→ 企画チェック(別エージェント)
4. **本文とイラスト**(`content/japanese/articles/<slug>.md`、`status: draft`)
5. `node scripts/check-article.mjs <slug>`(ルビ、type、内部リンクなどを機械で確認)
6. **本文チェック**(別エージェント。5章の項目を追加)
7. **Kaz のレビュー**(完成した記事を見る。日本語の自然さの一次確認は、6 のチェック担当が行う) → 承認されたら `published` にしてデプロイ。**最初の1本を公開した時点で、本番に日本語学習のメニューと英語のページ(/en/...)が現れる**

## 5. 本文チェックで足す項目

英語学習の 3-5 の項目(薄さ、事実、SEO、削っても困らない段落)に加えて:

- [ ] 日本語の例文が自然か(実際に言うか、場面に合うか)
- [ ] 文法の説明が正しいか。例外があるのに言い切っていないか(「always」「never」に注意)
- [ ] NG 例が、本当に誤りか(不自然なだけのものを NG にしていないか)
- [ ] ルビの読みが、その文脈で正しいか
- [ ] ローマ字の表記が3章のルールどおりか
- [ ] 例文の英訳が、日本語と同じ意味か(ニュアンスを足したり、落としたりしていないか)
- [ ] 英語の文章が自然で、むずかしすぎないか
- [ ] 例え話が、説明する仕組みと対応しているか。文化の決めつけがないか
- [ ] 上位の英語記事(主キーワードで検索)にない情報があるか

## 8. ハブとタグ(固定の一覧。Kaz 決定)

ここにないハブやタグは作らない。足したいときは Kaz に確認する。

- **ハブ(大分類。記事ごとに1つ)**: `Particles`(助詞)、`Grammar`(文法の形)、`Synonyms`(似た言葉)、`Politeness`(丁寧さ・敬語)、`Phrases`(決まった言い方)
- **タグ(記事ごとに3〜5個)**
  - ハブ: `Particles` `Grammar` `Synonyms` `Politeness` `Phrases`
  - レベル(1つ): `Beginner` `Intermediate` `Advanced`
  - JLPT(0〜1つ): `N5` `N4` `N3` `N2` `N1`
  - そのほか: `Verbs` `Adjectives` `Conversation` `Business`
- **JLPT タグの付け方**
  - JLPT は、レベルごとの単語・漢字・文法の公式リストを公開していない(JLPT 公式サイトの FAQ。https://www.jlpt.jp/e/faq/ で確認済み)。教科書や学習サイトの「N4 文法」の一覧は、それぞれ独自の目安
  - そのため、タグは「そのレベルでよく学ぶ」という目安として付け、本文でも「N4 の公式文法」とは書かない。書くなら `commonly studied around N4` のように書く
  - 迷うとき、レベルに関係しない記事には付けない
  - レベルとの対応の目安: N5・N4 = Beginner、N3 = Intermediate、N2・N1 = Advanced
