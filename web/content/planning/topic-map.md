# topic-map(テーマ管理表)

どの記事が、どの検索意図を狙うかを管理する。企画エージェントは、カードを作る前と、アウトラインを作る前に、必ずこのファイルを読む。
ルールは、指示書の1章「テーマ管理(topic-map)と、記事どうしの重複(カニバリ)対策」を参照。

**状態**: `card`(承認前) → `approved` → `outlined` → `draft` → `published`
**主キーワード**: その記事が狙う、ただ1つの検索語。同じ主キーワードの記事を、2本作らない。
**想定読者**: 仮の設定。検索データが集まったら、見直す。
**ID**: `A-xx` はワークフロー導入前の記事。`W40-xx` は2026年第40週の企画カード。
**slug**: `scripts/check-article.mjs` がこの列で記事を照合する。公開前は予定の slug を書く。

最終更新: 2026-10-01
